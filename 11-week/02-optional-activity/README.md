# Actividad Semana 11: Análisis de una Serie de Tiempo

##  1. Descripción de Tendencia y Estacionalidad
* **Tendencia:** Se observa una ligera estabilidad general a lo largo del periodo analizado, con variaciones moderadas entre los distintos trimestres del año.
* **Estacionalidad:** La serie muestra un comportamiento cíclico claro vinculado a los meses de mitad de año, donde los valores tienden a incrementar de forma repetitiva antes de volver a descender hacia el cierre del ciclo.

---

##  2. Requisitos Incluidos
* `analisis_serie.py`: Script en Python con la carga de datos en Pandas, índice temporal, agregación mensual (`resample`) y cálculo de media móvil (`rolling`).
* `serie_tiempo_grafico.png`: Gráfico generado con la comparativa de la serie y su media móvil.
